task 1---# Transaction Tracker

A simple and responsive **Transaction Tracker** web application built using **HTML, CSS, and JavaScript**.

It helps users easily manage their **income and expenses** and keep track of their current balance.

## Features

* Add income and expense transactions
* View total income
* View total expenses
* View current balance
* Edit transactions
* Delete transactions
* Save data using Local Storage
* Responsive design
* Simple and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## Project Structure

```text
Transaction-Tracker/
│
├── transaction trek.html
├── transaction.css
├── tr.js
└── images/
```

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `index.html`.
4. Run it using **Live Server** or open it in your browser.

## How It Works

1. Add a transaction.
2. Select **Income** or **Expense**.
3. Enter the amount and other details.
4. The balance is automatically updated.
5. Transactions are saved in the browser using **Local Storage**.

## Purpose

This project was created to practice frontend development and JavaScript concepts such as:

* DOM Manipulation
* Events
* Forms
* Arrays and Objects
* Local Storage
* Responsive Design

# To-Do List

A simple and responsive **To-Do List Web Application** built using **HTML, CSS, and JavaScript**.

This project helps users easily manage their daily tasks by adding, completing, editing, and deleting tasks.

## Features

* Add new tasks
* Edit existing tasks
* Mark tasks as completed
* Delete tasks
* View pending and completed tasks
* Search and filter tasks
* Save tasks using Local Storage
* Responsive design
* Simple and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## Project Structure

```text
To-Do-List/
│
├── to do list.html
├── to do.css
├── to do.js
└── images/
```

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `index.html`.
4. Run the project using **Live Server** or open it directly in your browser.

## How It Works

1. Enter a task in the input field.
2. Click the **Add Task** button.
3. The task will appear in the task list.
4. Mark the task as completed when finished.
5. Edit or delete the task whenever needed.
6. Tasks are saved in the browser using **Local Storage**.

## Purpose

This project was created to practice frontend development and JavaScript concepts such as:

* DOM Manipulation
* Event Handling
* Arrays and Objects
* Local Storage
* CRUD Operations
* Responsive Web Design
